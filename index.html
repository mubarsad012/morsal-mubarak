Open-source software & tools

Things I've built that you can open and use. Each one links to the live version and the code.

In beta · Released October 2026

ProxyHealth AI

An open-source web app that uses AI to explain medical and official paperwork in plain language, for families like mine and for refugees in my community.

  • Public beta, released October 2026
  • Explains paperwork in 27 languages, including Pashto and Dari
  • Python backend, which I taught myself
Live web app GitHub repository How it works →

The AI server runs on a free tier. After it has been idle, the first explanation can take 30–60 seconds while it wakes up.

An interactive calculator and data-audit dashboard built on my 33.5-million-record benchmark of U.S. birth, infant-death, and fetal-death records. It runs entirely in the browser.

Neuroimaging & Clinical Research: Traumatic Brain Injury (TBI) MRI Computational Study

Lead computational researcher for a 35-participant study of brain chemistry after traumatic brain injury. I built a verified Python pipeline (pandas, NumPy, SciPy, statsmodels) that links MR spectroscopy measurements to post-concussion symptoms, with outlier screening and multiple-comparison control.

See the pipeline & try the demo

PoxHostAtlas: Host Gene-Expression Remodeling During Poxvirus Infection

A cross-study atlas that re-analyzes public RNA-seq datasets to test which host-cell responses to poxviruses (including vaccinia) are reproducible, using meta-analysis, co-expression networks, and machine-learning stress tests.

Explore the atlas PDF
1,834host genes reproducibly changed across datasets
D
Mass General Brigham · MGH Martinos CenterOct 2026Poster presented

Brain Metabolism in Long COVID (COVID-BRAIN)

Co-author of a poster, and 2nd author on the manuscript in preparation, from the multicenter COVID-BRAIN imaging study, which found lower thalamic glutathione and creatine in people with neurological Long COVID, linked to cognition and inflammation. Presented at Mass General Brigham Clinical Research Day 2026.

See the findings
176participants analyzed (102 Long COVID, 74 controls)

Senior (last) authorManuscript in preparationSystematic review

AI-Guided Diagnostics for Neurocysticercosis: ESM-2 + AlphaFold

A systematic review of whether protein language models (ESM-2) and AlphaFold structures can find antibody targets for a cheaper blood test for neurocysticercosis, the leading cause of acquired epilepsy worldwide.

Read the review summary

Section IV · About / CV

About me

I'm an IB Diploma candidate at Justice High School in Falls Church, Virginia (Class of 2027). I learned to code mostly by building things I needed, like a tool that explains the paperwork my family and neighbors get, and a benchmark on 33.5 million U.S. birth records that anyone can re-run.

I want my research to be easy to check. My fetal-growth benchmark and PoxHostAtlas both come with public code, data manifests, and file hashes. I also try to explain results in words a family can follow.
